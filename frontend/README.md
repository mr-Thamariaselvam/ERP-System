# Getting Started with ERP System (Next.js)

This project was bootstrapped with **Next.js** using `create-next-app`.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.
You may also see lint errors in the console.

---

### `npm run build`

Builds the app for production to the `.next` folder.
It correctly bundles the application in production mode and optimizes the build for best performance.

The build output is optimized and ready for deployment.

---

### `npm start`

Runs the app in production mode.
You must run `npm run build` before running this command.

---

### `npm run lint`

Runs ESLint to check for code quality and formatting issues.

---

### `npm run format`

Formats the codebase using Prettier.

---

### `npm run stylelint`

Checks SCSS/CSS files using Stylelint.

---

### `npm run stylelint:fix`

Automatically fixes Stylelint issues where possible.
